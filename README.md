## Featured Projects

### Project 1: BACE1 Inhibitor Analysis - Alzheimer's Drug Discovery

Course: [INTEG 275 - Fundamentals of AI for Science]  
University: [University of Waterloo] 
Field: [Physical Sciences and Biomedical Applications]

This academic project investigates how artificial intelligence and machine learning can be applied to molecular data to study potential inhibitors of beta-secretase 1 (BACE1).

BACE1 is an enzyme involved in the production of amyloid-beta peptides, which have been studied in relation to Alzheimer's disease.

The project involves analyzing 1,513 molecular compounds using molecular descriptors such as molecular weight, hydrophobicity, hydrogen-bond counts, polar surface area, and ring counts.

The research aims to explore how classical machine learning methods can help identify relationships between chemical properties and experimentally measured inhibitory activity.

Project Objectives:

1. Explore and understand the molecular dataset.
2. Analyze relationships between molecular properties and BACE1 inhibitory activity.
3. Use Principal Component Analysis (PCA) to visualize chemical feature patterns.
4. Apply classification methods to predict compound activity.
5. Apply regression methods to estimate pIC50 values.
6. Evaluate model performance and discuss limitations in scientific prediction.

Project Details:

- 🔧 **Stack:** Python, pandas, matplotlib, scikit-learn, GitHub Copilot, and VS Code (planned)
- 🌐 **Live Demo:** Not yet available - project in development
- 📁 **Repository:** [BACE1 Inhibitor Analysis](https://github.com/Meeef04/alzheimers_drug_discovery.csv)
- 📊 **Dataset:** alzheimers_drug_discovery.csv
- 🚀 **Status:** Technical setup and introductory development

Scientific Note:

The dataset contains laboratory-tested research compounds rather than approved medications. The models developed in this project are intended for exploratory scientific analysis and do not demonstrate that any compound treats Alzheimer's disease.
